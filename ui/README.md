# Bioritmic UI

Angular приложение для проекта Bioritmic.

## Быстрый старт

### Запуск сервера разработки

```bash
# Через gradle (из корня проекта)
./gradlew startUi

# Или через npm (из папки ui/)
cd ui
npm run start
```

Сервер будет доступен по адресу: http://localhost:2399

### Сборка приложения

```bash
# Через gradle (из корня проекта)
./gradlew buildUi

# Или через npm (из папки ui/)
cd ui
npm run build
```

### Другие команды

```bash
# Запуск тестов
npm run test

# Линтинг кода
npm run lint

# Сборка в режиме разработки (watch mode)
npm run watch
```

## Структура проекта

```
ui/
├── src/
│   ├── app/
│   │   ├── core/           # Сервисы, модели, гарды, интерсепторы
│   │   ├── features/       # Функциональные модули (auth, profile, search и т.д.)
│   │   ├── shared/         # Общие компоненты
│   │   └── app.routes.ts   # Маршруты приложения
│   ├── assets/             # Статические ресурсы
│   └── main.ts             # Точка входа
├── package.json
├── angular.json
└── proxy.conf.json         # Прокси для API запросов
```

## Доступные страницы

| Страница | Маршрут | Описание |
|----------|---------|----------|
| Авторизация | `/auth/login` | Вход в систему |
| Регистрация | `/auth/registration` | Регистрация нового пользователя |
| Восстановление пароля | `/auth/recovery` | Восстановление доступа |
| Поиск | `/search` | Поиск пользователей |
| Профиль | `/profile/me` | Просмотр своего профиля |
| Редактирование профиля | `/profile/me/edit` | Редактирование профиля |
| Страница пользователя | `/user/:id` | Просмотр профиля другого пользователя |
| Закладки | `/bookmarks` | Избранные пользователи |
| Сообщения | `/mailbox` | Почта |
| Встречи | `/meetings` | Предложения встреч |
| Настройки | `/settings` | Настройки поиска |
| Местоположение | `/settings/location` | Управление GIS данными |
| Заблокированные | `/settings/blocked` | Список заблокированных |

## API Proxy

Для разработки настроен прокси на `http://localhost:7078`. Измените `proxy.conf.json` если API находится на другом порту.

## Требования

- Node.js 20.x
- npm 10.x
